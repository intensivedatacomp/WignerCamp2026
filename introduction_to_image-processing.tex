\begin{frame}{Can Computers Really See?}

    A camera only captures millions of numbers.

    \begin{center}
        Image = Matrix of Pixels
    \end{center}

    For a computer:

    \begin{itemize}
        \item A person is not a person.
        \item A road is not a road.
        \item A wall is not a wall.
    \end{itemize}

    Everything starts as numbers.
\end{frame}

%------------------------------------------------
\begin{frame}{The Challenge}

    Humans instantly recognize:

    \begin{itemize}
        \item Roads
        \item Faces
        \item Buildings
        \item Obstacles
    \end{itemize}

    Computers must learn how to find useful information inside an image.

    This is where \textbf{Computer Vision} begins.
\end{frame}

%------------------------------------------------
\begin{frame}{What Is an Edge?}

    An edge is a place where brightness changes suddenly.

    \vspace{0.5cm}

    Examples:

    \begin{itemize}
        \item Border of a road
        \item Corner of a building
        \item Outline of a person
        \item Edge of a traffic sign
    \end{itemize}

    Edges often describe the shape of objects.
\end{frame}

%------------------------------------------------
\begin{frame}{Why Is Edge Detection Important?}

    Without edge detection:

    \begin{itemize}
        \item Too much information
        \item Difficult to identify objects
    \end{itemize}

    With edge detection:

    \begin{itemize}
        \item Important structures become visible
        \item Less data to process
        \item Faster algorithms
    \end{itemize}
\end{frame}
